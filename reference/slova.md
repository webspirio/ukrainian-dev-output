# Слова й звороти для технічного тексту

Як писати у власному тексті: відповіді, звіти, документація. Ліва колонка — те, що моделі часто пишуть, права — простіше й природніше. Обґрунтування й джерела кожної пари — у `research/v1/skill/reference/kalky.md` і `research/review/02_kalky.md`.

## Прийменники

| Не так | Так |
|---|---|
| при запуску, при виконанні запиту | під час запуску, коли виконується запит |
| при помилці, при недоступному сервісі | якщо станеться помилка, якщо сервіс недоступний |
| у випадку помилки | у разі помилки, якщо станеться помилка |
| по причині таймауту | через тайм-аут |
| у зв'язку з обмеженнями | через обмеження |
| в залежності від | залежно від |
| у відповідності з, згідно до | відповідно до, згідно з |
| в якості ключа | як ключ |
| по відношенню до | щодо |
| документація по API, питання по деплою | документація з API, питання щодо деплою |
| на протязі години | протягом години |
| за рахунок кешування | завдяки кешуванню |

## Дієслова й звороти

| Не так | Так |
|---|---|
| здійснити перевірку, виконати пошук, провести налаштування | перевірити, знайти, налаштувати |
| з метою підвищення швидкодії | щоб пришвидшити |
| дозволяє уникнути (не про дозвіл) | дає змогу уникнути |
| включає в себе | містить |
| включаючи тести | зокрема тести |
| складає 200 мс | становить 200 мс |
| приводить до падіння | призводить до падіння |
| співпадає | збігається |
| заключається в | полягає в |
| має місце помилка | виникає помилка |
| процес продовжується | процес триває |
| слідувати інструкції | виконувати інструкцію |
| приймати до уваги | брати до уваги |
| прийти до висновку | дійти висновку |
| вирішувати задачу (алгоритмічну) | розв'язувати задачу |
| як виглядає процес | як працює процес, як побудовано процес |
| є сенс додати | варто додати |
| робить сенс | має сенс |
| адресувати проблему | розв'язати проблему, взятися за проблему |
| фокусуватися на | зосередитися на |
| у кінці дня (at the end of the day) | зрештою |

## Сполучники й зв'язки

| Не так | Так |
|---|---|
| так як (причина) | бо, оскільки |
| значить (як «отже») | отже, тож |
| чим більше, тим швидше | що більше, то швидше |
| до тих пір, поки | доки |
| до цих пір | досі |
| тим не менше | проте, однак |
| являється | є |
| X є Y | X — Y, X — це Y |
| будь то | чи то |
| виконайте наступні кроки: | виконайте такі кроки: |

## Прикметники й дієприкметники

| Не так | Так |
|---|---|
| слідуючий | наступний |
| існуючий | наявний |
| працюючий сервер | сервер, що працює |
| конфліктуючі зміни | конфліктні зміни |
| керуючий символ | керувальний символ |
| вірний (= правильний) | правильний |
| невірний пароль | хибний пароль |
| даний метод | цей метод |
| на даний момент | зараз |

Нормальні, хоча схожі на кальки: «блискучий», «спливаюче вікно», «діюча речовина»; «задача» в алгоритміці; «так, як у прикладі» (порівняння); «за замовчуванням»; дієприслівники «використовуючи», «запускаючи».

## Форми, які плутають

| Не так | Так |
|---|---|
| Відповіси на питання | Дай відповіді на питання, Відповідай |
| одного тесту з шести не проходить | один тест із шести не проходить |
| два тести падає | два тести падають |
| 5 файлів змінено, 1 файлів додано | змінено 5 файлів, додано 1 файл |
| значення таймеру | значення таймера (але: коду, файлу, запиту) |
| проект, проектування | проєкт, проєктування |
| таймаут | тайм-аут |
| вебсайт, веб сайт | вебсайт |
| у S3 bucketі | у S3-бакеті |

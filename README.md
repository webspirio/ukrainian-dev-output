# ukrainian-dev-output

A Claude Code skill for writing clear, concise Ukrainian for developers: terminal replies, task reports, error explanations, plans, docs, commit messages and PR descriptions — without calques (кальки) or filler (вода).

## Install

```sh
git clone https://github.com/webspirio/ukrainian-dev-output ~/.claude/skills/ukrainian-dev-output
```

## Contents

- `SKILL.md` — response structure, templates and rules
- `reference/kalky.md` — common calques and their correct forms
- `reference/slova.md` — word choices for technical text
